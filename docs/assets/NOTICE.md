# Third-party assets

For research purposes only; not an official Drupal.org page.

- `stylesheets/drupal-pages.css`, `javascripts/drupal-pages.js` and
  `mkdocs-overrides/` are copied from the Site Agent project
  (https://git.drupalcode.org/project/site_agent, GPL-2.0-or-later). The
  stylesheet imitates the Drupal.org look using the Drupal brand palette.
- `fonts/noto-sans/` is Noto Sans under the SIL Open Font License
  (`OFL.txt`).
- ZT Gatha (the Drupal.org heading face) is not bundled: it is free for
  personal use only, so headings fall back to Noto Sans.
